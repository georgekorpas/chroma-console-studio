Settings & help

Your connection, controls and saved sounds.

Connect your pedal

  1. Power Chroma Console normally and connect its USB cable to your Mac.
  2. Use Chrome or Edge. Select Connect MIDI and allow MIDI access.
  3. Match the MIDI channel to the pedal. The default is channel 1. Live control starts automatically.

If it doesn’t respond, check the channel and exit any pedal menus. USB carries MIDI control; sound stays on the pedal’s audio connections.

Editor & pedal state

The editor follows supported MIDI messages it receives. Our test confirmed that the pedal’s physical knob movements do not send parameter feedback, so those changes cannot be mirrored here.

Blank values have not been set or reported. The Engage toggle shows the last commanded or reported state. Preset recall clears values because the pedal does not provide a documented preset readback.

Moving a control sends that change. Loading a local preset prepares it in the editor; Apply loaded preset applies its saved settings. The Apply button appears only when there are unsent settings; live edits need no extra step.

About local presets

A local preset contains parameter overrides, optionally based on one of your 80 pedal slots. It is not a complete backup of the pedal.

Bypass, tempo, calibration, captured audio and Gesture data are excluded. Select Off in an effect list to save a module as off. Configure module order, expression mapping and dual-bypass assignment on the pedal.

Presets are stored in this browser. Export your library to keep a backup.

Device access

The editor sends only documented control-change and preset-selection messages. SysEx is disabled. No bootloader, reset, updater or firmware controls are included.

The app uses no accounts, analytics or cloud storage.

In the pedal’s default interface mode, USB MIDI is forwarded to DIN MIDI OUT. Connected devices can respond on the same channel.
